## About

I am Paco, a student building a portfolio of end-to-end data science projects. I enjoy taking a messy dataset, understanding the problem behind it, training a model carefully, and turning the result into something people can interact with.

My current work sits at the intersection of:

- Applied machine learning and model comparison
- Natural language processing and text classification
- Customer analytics and prediction
- Cybersecurity and anomaly detection
- Recommendation systems and ranking

I care about honest evaluation, clear documentation, reproducible workflows, and useful demos.

## How I Build

```text
dataset -> investigation -> preprocessing -> modeling -> evaluation -> usable demo
```

Each project is designed as a small, complete system rather than a model-only exercise. I compare meaningful baselines, document trade-offs, preserve notebook outputs for review, and expose the final work through a lightweight application where it makes sense.
