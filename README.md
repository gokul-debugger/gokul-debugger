## `01` / About

I am Paco, a student building end-to-end data science projects. I like taking a real dataset from investigation to evaluation, then turning the result into a small application people can actually use.

My work focuses on applied machine learning, NLP, customer analytics, cybersecurity, and recommendation systems. I value clear experiments, honest metrics, reproducible workflows, and practical demos.
